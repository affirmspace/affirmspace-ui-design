# affirmspace-ui-design
UI/UX design repository for Affirmspace — an LGBTQ+ focused mental wellness, emotional wellbeing, and safe community platform.
This repository contains:
- Mobile app UI concepts
- LGBTQ+ inclusive design explorations
- Emotional wellness interface ideas
- Safe social interaction layouts
- Branding and visual identity concepts
- User experience flows and onboarding screens
The goal of Affirmspace is to create a calming, supportive, and inclusive digital environment where people can connect safely and express themselves freely.
Focus Areas:
- LGBTQ+ community support
- Mental wellness
- Queer social connection
- Inclusive UI/UX
- Emotional safety
- Human-centered design
Website: https://affirmspace.com
